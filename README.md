# LendingClub Credit Risk

Would a 2007 credit model survive 2008 — and would you notice in time?
Application scorecard, monitoring (PSI/KS), vintage analysis, and lifetime-PD / stress-test extensions on public LendingClub data.

Data: LendingClub, via the Kaggle dataset by Nathan George (wordsforthewise). Raw data is not included in this repository.
